LANGKAH 1 · ±10 menit

Salin template dan online-kan dengan Vercel

Vercel adalah tempat aplikasimu di simpan dan ditayangkan di internet.Tombol Deploy di bawah otomatis menyalin template ke akun GitHub-mu dan langsung bisa tayang.

  1. Klik tombol hitam di bawah ini : ▲ Deploy with Vercel
  2. Pilih Continue with GitHub , lalu izinkan akses kalau diminta. Gambar: login Vercel dengan Continue with GitHub
  3. Di kolom Repository Name , isi nama tanpa spasi, misalnya katalog-budi , kalau saya diisi titrasi-coffe . Pastikan gembok berwarna orange Gambar: proses clone Repository. setelah itu Klik Create .
  4. Tunggu proses deploy sampai muncul tulisan Congratulations (±1–2 menit). Gambar: halaman Congratulations setelah deploy
  5. Klik gambar pratinjau atau tombol Continue to Project Gambar: Continue to Project Lalu klik link domain yang (berakhiran .vercel.app ). Gambar: Tampilan Project yang berhasil di domain titrasi-coffe.vercel.app
  6. Catat link ini, nanti dikumpulkan.
✓ Hasil yang diharapkanHalaman "Toko Contoh" tampil dengan 6 produk contoh dan tulisan "Masih data contoh". Ini normal: aplikasimu sudah online, tapi belum tersambung ke database.

LANGKAH 2 · ±5 menit

Buat proyek database di Supabase

Supabase adalah tempat menyimpan data produk dan akun admin tokomu.

  1. Buka supabase.com , klik Sign in , pilih Continue with GitHub . Gambar: Supabase
  2. Klik New Organization . Gambar: tombol New Organization
  3. Isi Project name (misalnya Discaleup ).
  4. Isi Database Password (klik Generate juga boleh). Simpan password ini di catatan HP.
  5. Pilih Region : Southeast Asia (Singapore) .
  6. Klik Create new project , lalu tunggu sampai selesai (±2 menit). Gambar: tombol Create new project
✓ Hasil yang diharapkanDashboard proyek terbuka, menu di kiri berisi Table Editor, SQL Editor, Authentication, dan lainnya.
3
LANGKAH 3 · ±5 menit

Buat tabel produk dengan skrip

Skrip ini membuat tabel produk, mengisi 6 produk awal, dan memasang aturan keamanan database.

  1. Buka repo GitHub-mu (yang baru dibuat di Langkah 1, alamatnya github.com/akunmu/nama-repo ), masuk ke folder docs , klik file schema.sql . Isinya sama dengan schema.sql di repo template . Gambar: file docs/schema.sql di repo GitHub
  2. Klik ikon Copy raw file (ikon dua kotak di kanan atas isi file).
  3. Di Supabase, buka menu SQL Editor di seblah kiri. Pastikan SQL Editor BUKAN Table Editor
  4. Tempel (Ctrl+V / Cmd+V) seluruh isi ke kotak editor.
  5. Klik tombol Run di kanan atas. Gambar: tombol Run dan hasil Success
  6. Buka menu Table Editor , klik tabel produk . Gambar: tabel produk di Table Editor
✓ Hasil yang diharapkanMuncul tulisan "Success. No rows returned", dan di Table Editor tabel produk berisi 6 baris produk.

LANGKAH 4 · ±5 menit

Buat akun admin toko

Akun ini dipakai pemilik toko untuk masuk ke halaman admin. Password bawaannya nanti wajib kamu ganti di Langkah 13.

  1. Di Supabase, buka menu Authentication , lalu Users . Gambar: menu Authentication → Users
  2. Klik Add user , pilih Create new user . Gambar: Add user → Create new user
  3. Isi email dan password bawaan yang ditampilkan mentor di layar . Gambar: isian email dan password admin
  4. Centang Auto Confirm User , lalu klik Create user .
  5. Masih di Authentication, buka Sign In / Providers . Matikan pilihan Allow new users to sign up , lalu klik Save . Gambar: mematikan Allow new users to sign up
✓ Hasil yang diharapkanAda 1 pengguna di daftar Users, dan pendaftaran akun baru sudah dimatikan (supaya orang lain tidak bisa membuat akun admin di tokomu).

LANGKAH 5 · ±10 menit

Sambungkan Vercel ke Supabase

Aplikasi butuh 3 kunci untuk bisa membuka database. Kunci ini rahasia: jangan dibagikan ke siapa pun.

  1. Di Supabase, ambil 3 nilai berikut (nama menu bisa sedikit berbeda, tanya pendamping kalau tidak ketemu): Project Settings → Data API → Project URL. Bentuknya https://xxxx.supabase.co . Project Settings → API Keys → Publishable key , berawalan sb_publishable_ . Secret key : di halaman yang sama, berawalan sb_secret_ . Klik ikon mata untuk menampilkan, lalu salin. Gambar: lokasi Project URL dan API keys di Supabase Gambar: lokasi Project URL dan API keys di Supabase Gambar: lokasi Project URL dan API keys di Supabase Gambar: lokasi Project URL dan API keys di Supabase
  2. Buka dashboard Vercel, klik proyekmu, lalu Settings → Environment Variables . Gambar: Settings → Environment Variables di Vercel
  3. Tambahkan 3 variabel ini satu per satu (Key di atas, Value di bawah), lalu klik Save : Gambar: tiga environment variable sudah terisi
PERINTAH GIT / TERMINAL 
Key:   SUPABASE_URL
Value: (Project URL)

Key:   SUPABASE_PUBLISHABLE_KEY
Value: (Publishable key)

Key:   SUPABASE_SECRET_KEY
Value: (Secret key)
✓ Hasil yang diharapkanDeploy ulang selesai tanpa error. Halaman aplikasi masih menampilkan data contoh. Ini normal: kuncinya sudah terpasang, tapi kodenya baru akan disambungkan ke database di Langkah 9.

LANGKAH 8 · ±15 menit

Ubah identitas toko dan kirim perubahan pertama

  1. Buka file lib/toko.js . Ganti isi di dalam tanda kutip: nama toko, tagline, alamat, jam buka.
  2. Ganti nomorWhatsApp dengan nomor usaha, format internasional tanpa tanda + dan tanpa angka 0 di depan. Contoh: 6281234567890 .
  3. Simpan, lalu cek localhost:3000 : nama toko sudah berubah.
  4. Buka terminal baru ( Terminal → New Terminal , biarkan yang lama tetap berjalan), lalu kirim perubahan:
PERINTAH GIT / TERMINAL 
git add .
git commit -m "Kustomisasi identitas toko"
git push
✓ Hasil yang diharapkanSetelah ±1 menit, link Vercel-mu juga menampilkan nama toko yang baru. Artinya alur kerja sudah benar: ubah di laptop → push → Vercel otomatis memperbarui.

LANGKAH 12 · US-04

Login admin

PROMPT AI AGENT 
Baca AGENTS.md bagian aturan keamanan dan docs/user-stories.md bagian US-04.

Buat login admin memakai Supabase Auth (email dan password) dengan @supabase/ssr dan cookie, memakai SUPABASE_URL dan SUPABASE_PUBLISHABLE_KEY. Login diproses dengan Server Action di app/admin/actions.js dan disambungkan ke form di app/admin/login/page.jsx. Login berhasil diarahkan ke /admin; login gagal menampilkan pesan error yang jelas di halaman login. Buat juga tombol "Keluar" di components/NavAdmin.jsx berfungsi: mengakhiri sesi lalu kembali ke /admin/login. Jangan ubah tampilan. Hapus CatatanBelumAktif dari halaman login.
PERINTAH GIT / TERMINAL 
git add .
git commit -m "US-04: login admin"
git push
✓ Hasil yang diharapkanBuka localhost:3000/admin/login, masuk dengan password salah: muncul pesan error.Masuk dengan email dan password bawaan dari Langkah 4: masuk ke halaman daftar produk admin.Klik Keluar: kembali ke halaman login.
